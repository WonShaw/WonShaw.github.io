URL Encoder

Offline-only: no server requests.

Mode

Use encodeURIComponent for query values and path segments; it escapes reserved characters like ? & = / #. Use encodeURI for a full URL, which keeps those separators intact.

Plain Text

Type or paste text, then encode it.

Encoded Text
